# Exam Prep Bot

Telegram-бот для подготовки к экзаменам по загруженным материалам.

## Что умеет

- принимает PDF, DOCX и TXT;
- создаёт короткий тест: определение, 2 тестовых и 1 открытый вопрос;
- создаёт полный тест: 8 тестовых и 2 открытых вопроса;
- не создаёт новый тест, пока не завершён предыдущий;
- проверяет ответы через OpenAI API;
- показывает средний балл и слабые темы;
- напоминает о подготовке и незавершённых тестах.

## Запуск

Нужен Python 3.11 или новее.

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="токен-из-BotFather"
export OPENAI_API_KEY="ключ-OpenAI"
export DATABASE_URL="postgresql://..."
python bot.py
```

Остальные настройки и их примеры находятся в `.env.example`.

## Как пользоваться

1. Открыть бота и нажать `/start`.
2. Отправить учебный PDF, DOCX или TXT.
3. Выбрать короткий или полный тест.
4. Отвечать по одному вопросу; после последнего бот выдаст разбор.

Данные каждого пользователя изолированы по Telegram ID и хранятся в PostgreSQL.

## Railway

1. Подключить этот GitHub-репозиторий как новый сервис.
2. Добавить к проекту PostgreSQL — Railway сам создаст `DATABASE_URL`.
3. В Variables добавить `TELEGRAM_BOT_TOKEN`, `OPENAI_API_KEY` и `OPENAI_MODEL=gpt-5-mini`.
4. Railway запустит бота командой из `Procfile`.

## Ограничение первой версии

В генерацию передаются последние 80 000 символов загруженных материалов. Этого достаточно для обычных методичек; поиск по большим библиотекам стоит добавлять только при реальной необходимости.
